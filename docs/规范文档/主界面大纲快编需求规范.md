### 1.5 项目卡片

```
┌────────────────────────┐
│                        │
│     16:9 缩略图         │ ← #222 纯灰
│     [▶ 播放按钮overlay] │
│                        │

│ 城市宣传片    [⋯]       │ ← 项目名 + 更多菜单

└────────────────────────┘
```

**Tag 颜色：**

| 类型 | 背景 | 文字 |
|------|------|------|
| MR混合 | accent-bg | accent |
| 静态图像 | rgba(safe,0.1) | safe |
| 动画 | rgba(marker,0.1) | marker |

**Hover：** `border-color: rgba(122,158,196,0.15)`

**默认项目（8个）：**
城市宣传片 / 产品展示动画 / 品牌Logo设计 / 音乐MV / 游戏过场 / 教程视频 / 广告短片 / 绘本故事

**新建项目卡片（第一个）：**
- 虚线边框 `2px dashed var(--ho-border-active)`
- 中央大 `+` 图标
- hover：实线 + accent 边框

### 1.6 新建项目对话框

## 二、视频工程 · 项目大纲

### 2.1 布局（三栏）

```
┌──────────┬──────────────────────────┬──────────┐
│          │                          │          │
│ 项目结构树 │     脚本编辑器            │  素材库   │
│ (240px)  │     (flex-1)            │  (280px) │
│          │                          │          │
└──────────┴──────────────────────────┴──────────┘
```

### 2.2 左栏 — 项目结构树

**标题：** "项目大纲"（14px 老京华体）

**树形结构：**
```
📁 场景1：开场          ← 展开态
   🎬 镜头1.1          ← 选中态 accent-bg
   🎬 镜头1.2
   🎬 镜头1.3
📁 场景2：主体展示       ← 折叠态
📁 场景3：结尾
```

**节点样式：**
- 缩进 16px/级
- 图标 emoji 前缀
- 12px secondary 色
- hover：primary 色 + rgba(255,255,255,0.04) 背景
- 选中：accent 色 + accent-bg 背景

**底部按钮：** `+ 添加场景` / `+ 添加镜头`

### 2.3 中栏 — 脚本编辑器

**镜头信息栏：**
```
[镜头1.1 - 开场] | [时长: 00:05:00] | [1920×1080]
```
12px secondary 色

**编辑区（contenteditable）：**

| 段落类型 | 样式 | 示例 |
|----------|------|------|
| 场景描述 | primary 色，14px | 城市黄昏全景，镜头从高空缓缓下降... |
| 对白 | accent 色说话人 + primary 正文 | **旁白** 在这座城市里... |
| 动作指示 | secondary 色，斜体 | （镜头缓慢推进，光线逐渐变化） |
| 镜头指示 | info 色 bg，12px，圆角 | 运动：垂直下降 + 缓慢推进 |

**底部工具栏：**
- B / I / U 按钮（28×28px）
- 段落下拉（场景描述/对白/动作指示/镜头指示）
- 字数统计（右对齐，11px tertiary）

### 2.4 右栏 — 素材库

**Tab 栏：** 视频 / 图片 / 音频 / 特效

**搜索框**

**素材网格（2列）：**
- 8 个卡片
- 16:9 缩略图（深灰纯色）
- 文件名 + 时长
- 底部：`+ 导入素材` 按钮

## 三、视频工程 · 快速编排

### 3.1 布局（三栏）

```
┌──────────┬──────────────────────────┬──────────┐
│          │                          │          │
│ 素材列表  │      故事板               │   属性   │
│ (240px)  │      (flex-1)           │  (240px) │
│          │                          │          │
└──────────┴──────────────────────────┴──────────┘
```

### 3.2 左栏 — 素材列表

- 搜索框
- 类型筛选 Chips（全部/视频/图片/音频）
- 列表项（每项）：
  ```
  [48×28px 缩略图] [文件名 flex-1] [时长]
  ```
- `draggable="true"` 标注

**默认素材（6个）：** 城市航拍 / 日落延时 / 公园全景 / 夜景灯光 / 街道人流 / 河流水面

### 3.3 中栏 — 故事板

**顶部工具栏：**
- 自动编排按钮
- 清空按钮
- 单片段时长：number input + "秒"

**故事板卡片序列（水平滚动）：**

每张卡片：
```
┌──────────────────┐
│   16:9 缩略图     │
│              00:05│ ← 时长 badge
│ ════════════════ │ ← 底部淡入淡出指示条
└──────────────────┘
       →              ← 连接箭头
┌──────────────────┐
│   16:9 缩略图     │
│              00:08│
│ ════════════════ │
└──────────────────┘
```

- 卡片宽度：200px
- 选中态：2px accent 边框
- 连接箭头：`→` tertiary 色

**底部状态栏：**
```
[总时长: 00:45]                    [发送到剪辑台 →]
```

### 3.4 右栏 — 属性

**素材信息：**
- 文件名
- 持续时间滑条（1-30s）
- 速度滑条（25-400%）

**过渡效果（6个卡片，2列网格）：**

| 效果 | 符号 |
|------|------|
| 溶解 | `✦` |
| 擦除 | `◆` |
| 推拉 | `◀▶` |
| 缩放 | `⊕` |
| 翻转 | `↻` |
| 百叶窗 | `≡` |

选中态：accent 边框 + accent-bg 背景

## 四、页面导航接入

| 操作 | 接口 | 说明 |
|------|------|------|
| 项目卡片点击 | `App.openProject(id)` | → `navigate('video')` + `switchTab('outline')` |
| 新建项目确认 | `App.createProject()` | → `navigate('video')` + `switchTab('outline')` |
| 侧边栏首页 | `App.navigate('main')` | |
| 侧边栏设置 | `App.navigate('settings')` | |
| 视频工程返回 | `App.navigate('main')` | ← 按钮在顶部栏左侧 |
| Tab 切换 | `VideoApp.switchTab(tabId)` | 7 个 tab |
| 底部 Tab 折叠 | 自动 8 秒 | 小尾巴点击/拖拽展开 |
