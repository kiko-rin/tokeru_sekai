# 二维工坊 · 调音面板 参数规范

---

## 一、效果器参数详解

### 1.1 EQ 均衡器

**类型：** 多段参数均衡器
**默认段数：** 8 段

| 频段 | 中心频率 | 范围 | 默认增益 | Q 值范围 | 默认 Q |
|------|----------|------|----------|----------|--------|
| 1 | 31 Hz | -12 ~ +12 dB | 0 | 0.1 ~ 10 | 1.0 |
| 2 | 62 Hz | -12 ~ +12 dB | 0 | 0.1 ~ 10 | 1.0 |
| 3 | 125 Hz | -12 ~ +12 dB | 0 | 0.1 ~ 10 | 1.0 |
| 4 | 250 Hz | -12 ~ +12 dB | 0 | 0.1 ~ 10 | 1.0 |
| 5 | 500 Hz | -12 ~ +12 dB | 0 | 0.1 ~ 10 | 1.0 |
| 6 | 1 kHz | -12 ~ +12 dB | 0 | 0.1 ~ 10 | 1.0 |
| 7 | 4 kHz | -12 ~ +12 dB | 0 | 0.1 ~ 10 | 1.0 |
| 8 | 8 kHz | -12 ~ +12 dB | 0 | 0.1 ~ 10 | 1.0 |

**控件布局：** 8 个竖直滑条横排，底部频率标签，增益值 hover 显示

**频段类型（可切换）：**
- Peak（峰值）— 默认
- Low Shelf（低架）
- High Shelf（高架）
- Low Pass（低通）
- High Pass（高通）
- Notch（陷波）

### 1.2 压缩器

| 参数 | 类型 | 范围 | 默认 | 单位 | 说明 |
|------|------|------|------|------|------|
| 阈值 (Threshold) | range | -60 ~ 0 | -20 | dB | 触发压缩的电平 |
| 比率 (Ratio) | select | 1:1 / 2:1 / 4:1 / 8:1 / 12:1 / 20:1 / ∞:1 | 4:1 | — | 压缩比例 |
| 起始 (Attack) | range | 0.1 ~ 100 | 10 | ms | 响应速度 |
| 释放 (Release) | range | 10 ~ 1000 | 100 | ms | 恢复速度 |
| 增益补偿 (Makeup) | range | 0 ~ +24 | 0 | dB | 输出增益补偿 |
| 膝点 (Knee) | select | Hard / Soft | Soft | — | 压缩过渡方式 |

**可视化：** 输入/输出曲线图（200×120px），阈值线，比率斜率线

### 1.3 混响

| 参数 | 类型 | 范围 | 默认 | 单位 | 说明 |
|------|------|------|------|------|------|
| 房间大小 (Room Size) | range | 0 ~ 100 | 40 | % | 虚拟空间大小 |
| 衰减 (Decay) | range | 0.1 ~ 10 | 2.0 | s | 混响尾音长度 |
| 预延迟 (Pre-Delay) | range | 0 ~ 100 | 20 | ms | 直达声与反射声间隔 |
| 高频衰减 (Damping) | range | 0 ~ 100 | 50 | % | 高频吸收量 |
| 干湿比 (Dry/Wet) | range | 0 ~ 100 | 30 | % | 效果混合比例 |

**预设：**
- 小房间 / 大厅 / 教堂 / 板式混响 / 金属板 / 无限

### 1.4 延迟

| 参数 | 类型 | 范围 | 默认 | 单位 | 说明 |
|------|------|------|------|------|------|
| 延迟时间 (Time) | range | 1 ~ 2000 | 300 | ms | 延迟间隔 |
| 反馈 (Feedback) | range | 0 ~ 95 | 30 | % | 回声重复量 |
| 干湿比 (Dry/Wet) | range | 0 ~ 100 | 20 | % | 效果混合比例 |
| 同步 (Sync) | toggle | on/off | off | — | 同步到 BPM |
| BPM | number | 20 ~ 300 | 120 | — | 同步时的节拍 |

**同步模式：** 当 Sync 开启时，延迟时间自动计算为 BPM 的分数（1/4, 1/8, 1/16 等）

### 1.5 合唱 (Chorus)

| 参数 | 类型 | 范围 | 默认 | 单位 |
|------|------|------|------|------|
| 速率 (Rate) | range | 0.1 ~ 5 | 1.5 | Hz |
| 深度 (Depth) | range | 0 ~ 100 | 50 | % |
| 反馈 (Feedback) | range | 0 ~ 95 | 10 | % |
| 干湿比 (Dry/Wet) | range | 0 ~ 100 | 30 | % |
| 声部数 (Voices) | select | 2 / 3 / 4 | 2 | — |

### 1.6 失真 (Distortion)

| 参数 | 类型 | 范围 | 默认 | 单位 |
|------|------|------|------|------|
| 驱动 (Drive) | range | 0 ~ 100 | 30 | % |
| 类型 | select | 软削波 / 硬削波 / 管式 / 位破碎 | 软削波 | — |
| 混合 (Mix) | range | 0 ~ 100 | 20 | % |
| 音量 (Level) | range | -24 ~ +6 | -6 | dB |

### 1.7 限制器 (Limiter)

| 参数 | 类型 | 范围 | 默认 | 单位 |
|------|------|------|------|------|
| 天花板 (Ceiling) | range | -12 ~ 0 | -0.3 | dB |
| 释放 (Release) | range | 1 ~ 1000 | 50 | ms |
| 输入增益 | range | 0 ~ +24 | 0 | dB |

### 1.8 降噪 (Noise Reduction)

| 参数 | 类型 | 范围 | 默认 | 单位 |
|------|------|------|------|------|
| 降噪强度 | range | 0 ~ 100 | 50 | % |
| 噪声样本 | 按钮 | — | — | 采集噪声指纹 |
| 频率平滑 | range | 0 ~ 10 | 3 | 频段 |
| 时间平滑 | range | 0 ~ 100 | 20 | ms |

### 1.9 去齿音 (De-Esser)

| 参数 | 类型 | 范围 | 默认 | 单位 |
|------|------|------|------|------|
| 频率 | range | 2000 ~ 12000 | 6000 | Hz |
| 阈值 | range | -60 ~ 0 | -20 | dB |
| 强度 | range | 0 ~ 100 | 50 | % |
| 监听 | toggle | on/off | off | — |

### 1.10 去嗡嗡声 (De-Hum)

| 参数 | 类型 | 范围 | 默认 | 说明 |
|------|------|------|------|------|
| 频率 | select | 50 Hz / 60 Hz | 50 Hz | 工频选择 |
| 谐波数 | select | 1~10 | 5 | 消除的谐波数 |
| 强度 | range | 0 ~ 100 | 80 | % |
