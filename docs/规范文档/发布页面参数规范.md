# 二维工坊 · 发布页面 可选参数规范

## 一、视频编码

### 1.1 编码格式

| 值 | 全称 | FFmpeg编码器 | 特征 | 封装兼容 |
|----|------|-------------|------|----------|
| `H.264` | AVC | libx264 | 最广泛兼容，编码速度快 | MP4 / MKV / MOV |
| `H.265` | HEVC | libx265 | 同画质码率减半，编码较慢 | MP4 / MKV / MOV |
| `VP9` | — | libvpx-vp9 | Google 开源，Web 优化 | WebM / MKV |
| `AV1` | — | libaom-av1 | 最高压缩率，编码最慢 | WebM / MKV / MP4 |
| `Sony XDCAM 422` | — | mpeg2video | 广播级4:2:2 | MXF |
| `Sony XDCAM 444` | — | mpeg2video | 广播级4:4:4 | MXF |
| `Sony XAVC I` | — | mpeg4 | Sony Intra帧内压缩 | MXF / MP4 |
| `Sony XAVC L` | — | libx265 | Sony Long GOP | MXF / MP4 |
| `ProRes 422` | — | prores_ks | Apple 专业中间编码 | MOV |
| `ProRes 4444` | — | prores_ks | Apple 专业含Alpha | MOV |

**仅解码（导入）格式：**

| 值 | 全称 | FFmpeg编码器 | 说明 |
|----|------|-------------|------|
| `Sony X-OCN` | X-OCN | copy (需Sony插件) | Sony压缩Raw，仅解码导入，不支持编码输出 |

**默认：** H.264

### 1.2 封装格式

| 值 | 视频编码兼容 | 音频编码兼容 | 特征 |
|----|-------------|-------------|------|
| `MP4` | H.264 / H.265 / AV1 | AAC / OPUS / PCM | 最通用 |
| `MKV` | 全部 | 全部 | 无限制，开源 |
| `MOV` | H.264 / H.265 / ProRes | AAC / PCM | Apple 生态 |
| `WebM` | VP9 / AV1 | OPUS / Vorbis | Web 专用 |
| `MXF` | Sony XDCAM / XAVC / X-OCN | PCM / AAC | 广播/专业采集 |

**默认：** MP4

**联动规则：**
- 选 H.264/H.265 → 封装自动切 MP4
- 选 VP9 → 封装自动切 WebM
- 选 AV1 → 封装可选 WebM/MP4/MKV
- 选 Sony XDCAM/XAVC/X-OCN → 封装自动切 MXF

### 1.3 分辨率

| 值 | 尺寸 | 比例 | 别名 |
|----|------|------|------|
| `1280×720` | 1280×720 | 16:9 | 720p HD |
| `1920×1080` | 1920×1080 | 16:9 | 1080p FHD |
| `2560×1440` | 2560×1440 | 16:9 | 1440p QHD |
| `3840×2160` | 3840×2160 | 16:9 | 2160p 4K UHD |
| `自定义` | 用户输入 | — | 宽×高 |

**默认：** 1920×1080

**自定义模式：**
- 宽度 input (min 128, max 7680, step 2)
- 高度 input (min 128, max 4320, step 2)
- 锁定比例开关（默认开）

### 1.4 帧率

| 值 | 适用场景 |
|----|----------|
| `24` | 电影感 |
| `25` | PAL 广播 |
| `30` | 通用网络视频 |
| `48` | 高帧率电影 |
| `50` | PAL 高帧率 |
| `60` | 游戏/运动/高流畅 |

**默认：** 30

### 1.5 色度子采样

| 值 | 说明 | 适用编码 |
|----|------|----------|
| `4:2:0` | 色度水平减半，最常用 | H.264 / H.265 / VP9 / AV1 |
| `4:2:2` | 色度水平减半，广播级 | H.264(High422) / XDCAM / XAVC / ProRes |
| `4:4:4` | 色度全采样，专业级 | H.264(High444) / H.265(Main444) / XDCAM 444 / ProRes 4444 |

**默认：** 4:2:0

**联动规则：**
- Sony XDCAM 422 → 锁定 4:2:2
- Sony XDCAM 444 → 锁定 4:4:4
- Sony XAVC I → 锁定 4:2:2
- ProRes 422 → 锁定 4:2:2
- ProRes 4444 → 锁定 4:4:4
- VP9/AV1 → 仅支持 4:2:0

### 1.6 色深

| 值 | 说明 | 适用编码 |
|----|------|----------|
| `8-bit` | 标准色深，256级 | H.264 / VP9 / XDCAM |
| `10-bit` | 专业色深，1024级 | H.264(High10) / H.265 / XAVC / ProRes |
| `12-bit` | 高端色深，4096级 | H.265(Main12) |
| `16-bit` | 最高色深，65536级 | H.265(Main444-16) |

**默认：** 8-bit

**联动规则：**
- H.264 baseline/main → 锁定 8-bit
- H.264 high → 可选 8/10-bit
- H.265 main → 可选 8/10-bit
- H.265 main10 → 锁定 10-bit
- H.265 main444-16 → 锁定 16-bit
- Sony XDCAM → 锁定 8-bit
- Sony XAVC → 锁定 10-bit
- ProRes → 锁定 10-bit

### 1.7 码率模式

| 值 | 全称 | 说明 | 适用 |
|----|------|------|------|
| `CBR` | Constant Bitrate | 固定码率，文件大小可预测 | 直播/限速传输 |
| `VCRF` | Variable Constant Rate Factor | 恒定质量，码率浮动 | 通用最佳画质 |

**默认：** CBR

**切换联动：**
- CBR → 显示「视频码率」滑条
- VCRF → 显示「质量因子」滑条（0-51，默认 23，越低画质越高）

### 1.8 视频码率（CBR 模式）

| 参数 | 值 |
|------|-----|
| 类型 | range 滑条 + number input 联动 |
| 范围 | 1 - 100 Mbps |
| 步长 | 0.5 |
| 默认 | 20 Mbps |
| 显示 | `20 Mbps` |

**分辨率联动推荐值：**

| 分辨率 | 推荐码率 |
|--------|----------|
| 720p | 5-10 Mbps |
| 1080p | 15-25 Mbps |
| 1440p | 25-40 Mbps |
| 4K | 40-80 Mbps |

### 1.9 质量因子（VCRF 模式）

| 参数 | 值 |
|------|-----|
| 类型 | range 滑条 + number input |
| 范围 | 0 - 51 |
| 步长 | 1 |
| 默认 | 23 |
| 说明 | 0 = 无损，18 = 视觉无损，23 = 默认，28 = 较差，51 = 最差 |

### 1.10 编码器

| 值 | 全称 | 硬件 | 特征 |
|----|------|------|------|
| `软件编码` | x264/x265/libvpx/libaom | CPU | 质量最高，速度最慢 |
| `NVIDIA NVENC` | — | NVIDIA GPU | 速度快，质量中 |
| `AMD AMF` | — | AMD GPU | 速度快，质量中 |
| `Intel QSV` | — | Intel 集显 | 速度快，质量中 |

**默认：** 软件编码

**联动规则：**
- 仅 H.264/H.265 支持硬件编码
- VP9/AV1 → 自动锁定软件编码
- 硬件不可用时 → 灰化 + tooltip "未检测到GPU"

### 1.11 色彩空间

| 值 | 色域 | 动态范围 | 适用 |
|----|------|----------|------|
| `Rec.709` | sRGB | SDR | 通用 |
| `sRGB` | sRGB | SDR | Web 显示 |
| `Rec.2020` | 广色域 | HDR | HDR 显示器 |
| `DCI-P3` | 广色域 | HDR | 影院/Apple |

**默认：** Rec.709

**Sony/ProRes 编码特性：**

| 编码 | 色深 | 色度 | Profile | FFmpeg参数 | 方向 |
|------|------|------|---------|-----------|------|
| XDCAM 422 | 8-bit | 4:2:2 | xdcam_422 | mpeg2video -b 35000k | 编码输出 |
| XDCAM 444 | 8-bit | 4:4:4 | xdcam_444 | mpeg2video -b 44000k | 编码输出 |
| XAVC I | 10-bit | 4:2:2 | high422 | mpeg4 -coder 1 -bf 0 | 编码输出 |
| XAVC L (420) | 10-bit | 4:2:0 | main10 | libx265 -preset slow | 编码输出 |
| XAVC L (422) | 10-bit | 4:2:2 | main422-10 | libx265 -preset slow | 编码输出 |
| **X-OCN XT** | **16-bit** | **4:4:4** | XT | copy (需Sony RAW插件) | **仅解码导入** |
| **X-OCN ST** | **12-bit** | **4:4:4** | ST | copy (需Sony RAW插件) | **仅解码导入** |
| **X-OCN LT** | **12-bit** | **4:2:2** | LT | copy (需Sony RAW插件) | **仅解码导入** |
| ProRes 422 Proxy | 10-bit | 4:2:2 | proxy | prores_ks -profile 0 | 编码输出 |
| ProRes 422 LT | 10-bit | 4:2:2 | lt | prores_ks -profile 1 | 编码输出 |
| ProRes 422 Standard | 10-bit | 4:2:2 | standard | prores_ks -profile 2 | 编码输出 |
| ProRes 422 HQ | 10-bit | 4:2:2 | hq | prores_ks -profile 3 | 编码输出 |
| ProRes 4444 | 10-bit | 4:4:4 | 4444 | prores_ks -profile 4 | 编码输出 |
| ProRes 4444 XQ | 10-bit | 4:4:4 | 4444xq | prores_ks -profile 5 | 编码输出 |

> **X-OCN 注意事项：**
> - X-OCN 是 Sony Venice / CinemaLine 相机的压缩 Raw 采集格式
> - FFmpeg 原生不支持 X-OCN 解码，需要安装 Sony RAW 插件或使用 `ffprobe` 配合外部解码器
> - 解码后的帧数据为 12/16-bit Linear 或 S-Log3，进入调色管线处理
> - 推荐工作流：X-OCN (导入) → 内部 Linear Float32 处理 → 输出 ProRes/DNxHR

## 二、音频编码

### 2.1 编码格式

| 值 | 全称 | 有损/无损 | 兼容封装 |
|----|------|-----------|----------|
| `AAC` | Advanced Audio Coding | 有损 | MP4 / MKV / MOV |
| `FLAC` | Free Lossless Audio Codec | 无损 | MKV / MP4 |
| `OPUS` | — | 有损 | WebM / MKV |
| `PCM` | Pulse Code Modulation | 无损(原始) | MOV / MKV |

**默认：** AAC

### 2.2 音频码率（仅 AAC/OPUS）

| 值 | 说明 |
|----|------|
| `128 kbps` | 标准立体声 |
| `192 kbps` | 高质量立体声 |
| `256 kbps` | 专业级 |
| `320 kbps` | 最高有损质量 |

**默认：** 256 kbps

**联动规则：**
- FLAC / PCM → 码率字段灰化（无损无需设定码率）
- AAC / OPUS → 码率可选

### 2.3 采样率

| 值 | 说明 |
|----|------|
| `22050 Hz` | 低质量（语音） |
| `44100 Hz` | CD 标准 |
| `48000 Hz` | 视频标准 |
| `96000 Hz` | 高解析度 |

**默认：** 48000 Hz

### 2.4 声道

| 值 | 声道数 | 说明 |
|----|--------|------|
| `单声道` | 1 | 语音/播客 |
| `立体声` | 2 | 标准 |
| `5.1 环绕声` | 6 | 家庭影院 |
| `7.1 环绕声` | 8 | 高端影院 |

**默认：** 立体声

## 三、输出设置

### 3.1 输出路径

- 类型：input + 浏览按钮
- 默认：`/Users/Videos/`
- 浏览：Electron `dialog.showOpenDialog({ properties: ['openDirectory'] })`

### 3.2 文件名模板

- 类型：input
- 默认：`{project}_{date}`
- 支持变量：

| 变量 | 说明 | 示例 |
|------|------|------|
| `{project}` | 项目名称 | 城市宣传片 |
| `{date}` | 日期 YYYY-MM-DD | 2024-01-15 |
| `{time}` | 时间 HH-mm-ss | 14-30-00 |
| `{resolution}` | 分辨率 | 1920x1080 |
| `{fps}` | 帧率 | 30 |
| `{codec}` | 编码格式 | H264 |
| `{seq}` | 序号（自动递增） | 001 |

**输出示例：** `城市宣传片_2024-01-15.mp4`

### 3.3 渲染队列

| 参数 | 说明 |
|------|------|
| 添加到队列 | 不立即渲染，加入队列 |
| 队列管理 | 显示待渲染列表（预留） |
| 覆盖策略 | 同名文件：询问/覆盖/重命名 |

## 四、高级参数（折叠区）

### 4.1 编码高级

| 参数 | 类型 | 范围 | 默认 | 说明 |

**编码 Preset 选项：**

| 值 | 速度 | 质量 | 文件大小 |
|----|------|------|----------|
| ultrafast | ★★★★★ | ★ | 大 |
| superfast | ★★★★ | ★★ | 大 |
| veryfast | ★★★ | ★★★ | 中大 |
| faster | ★★★ | ★★★ | 中 |
| fast | ★★ | ★★★★ | 中 |
| medium | ★★ | ★★★★ | 中 |
| slow | ★ | ★★★★★ | 小 |
| slower | ★ | ★★★★★ | 小 |
| veryslow | ★ | ★★★★★ | 最小 |

## 六、参数联动矩阵

| 变更项 | 影响项 | 规则 |
|--------|--------|------|
| 编码格式 → H.264 | 封装 | 可选 MP4/MKV/MOV |
| 编码格式 → H.265 | 封装 | 可选 MP4/MKV/MOV |
| 编码格式 → VP9 | 封装 | 锁定 WebM/MKV |
| 编码格式 → AV1 | 封装 | 可选 WebM/MKV/MP4 |
| 编码格式 → VP9/AV1 | 编码器 | 锁定软件编码 |
| 编码格式 → X-OCN | 全部编码参数 | 灰化 (仅解码导入) |
| 素材为 X-OCN | 色彩空间 | 自动设为 S-Log3 + Rec.2020 |
| 素材为 X-OCN | 色深 | 自动设为 12/16-bit |
| 码率模式 → CBR | 码率滑条 | 显示，范围 1-100 Mbps |
| 码率模式 → VCRF | 质量滑条 | 显示，范围 0-51 |
| 分辨率变更 | 码率推荐值 | 自动调整滑条位置 |
| 音频编码 → FLAC/PCM | 音频码率 | 灰化 |
| 音频编码 → AAC/OPUS | 音频码率 | 可选 |
| 硬件编码器不可用 | 编码器选项 | 灰化 + tooltip |

## 七、渲染流程

```
[开始渲染]
    │
    ├─ 参数校验
    │   ├─ 封装/编码兼容性检查
    │   ├─ 硬件编码器可用性检查
    │   └─ 输出路径可写检查
    │
    ├─ 进度对话框
    │   ├─ 进度条 (百分比)
    │   ├─ 当前帧 / 总帧数
    │   ├─ 已用时间 / 预计剩余
    │   ├─ 渲染速度 (fps)
    │   └─ 取消按钮
    │
    ├─ 渲染完成
    │   ├─ 文件大小显示
    │   ├─ 打开文件按钮
    │   ├─ 打开所在文件夹按钮
    │   └─ 再次渲染按钮
    │
    └─ 错误处理
        ├─ 编码器不可用 → 提示切换
        ├─ 磁盘空间不足 → 提示清理
        └─ 编码失败 → 显示错误日志
```
