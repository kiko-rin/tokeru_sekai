| 启动时 | radio | 打开最近项目 / 显示开始页 / 新建项目 / 不做任何事 | 打开最近项目 | — |
| 自动保存 | toggle + number | on/off + 1-60 分钟 | on / 5 分钟 | — |

### 1.3 色彩管理 (ACE)

**自动色彩还原分组：**

| 参数 | 控件 | 选项 | 默认 | 说明 |
|------|------|------|------|------|
| 自动色彩还原 | toggle | on/off | on | 导入Log素材时自动还原 |
| 还原LUT库 | select | 内置 / 自定义 | 内置 | 指定还原用的LUT来源 |
| 默认还原LUT | select | 见LUT映射表 | 自动匹配 | 未识别厂商时使用的默认LUT |
| 强制覆盖已还原素材 | toggle | on/off | off | 重新还原已含LUT的素材 |

**自动色彩统一分组：**

| 参数 | 控件 | 范围 | 默认 | 说明 |
|------|------|------|------|------|
| 自动色彩统一 | toggle | on/off | on | 混合素材时统一色彩外观 |
| 统一强度 | range | 0~100% | 70% | 统一效果强弱 |
| 目标色温 | range | 2000~12000K | 5600K | 统一的目标色温 |
| 目标色调 | range | -100~+100 | 0 | 统一的目标色调偏移 |
| 目标饱和度 | range | 0~200% | 100% | 统一的目标饱和度 |
| 目标对比度 | range | 0.5~2.0 | 1.0 | 统一的目标对比度 |

**LUT库管理分组：**

| 参数 | 控件 | 说明 |
|------|------|------|
| LUT存储路径 | input + 浏览 | 程序本地LUT库位置 |
| 导入LUT | 按钮 | 支持 .cube / .3dl / .csp |
| 内置LUT数量 | 只读 | 显示当前已安装数量 |
| 清理未使用LUT | 按钮 | 释放本地存储空间 |

> **LUT存储策略：** LUT文件保存在程序本地目录（非引用），随项目打包。
> 剪辑素材为引用（仅保存路径），LUT为内嵌（复制到本地）。

**一键统一到ACE标准按钮：**
- 点击后自动设置所有色彩参数到ACE标准值
- 弹出确认对话框："将所有色彩参数重置为ACE标准？"
- 确认后应用：自动色彩还原=on, 自动色彩统一=on, 统一强度=70%, 目标色温=5600K

## 二、项目文件格式 (.2dw)

### 2.1 文件结构

```
project.2dw (ZIP 包)
├── project.json          ← 项目元数据 + 时间线数据
├── assets/               ← 素材引用（相对路径或嵌入）
│   ├── video/
│   ├── image/
│   ├── audio/
│   └── effects/
├── thumbnails/           ← 缩略图缓存
├── versions/             ← 版本历史
└── presets/              ← 项目内自定义预设
```

## 三、导入/导出格式支持

### 3.1 素材导入

| 类型 | 格式 | 编解码器 |
|------|------|----------|
| 视频 | MP4 / MOV / MKV / AVI / WebM | H.264 / H.265 / VP9 / ProRes / DNxHD |
| 视频(Raw) | MXF / MOV | Sony X-OCN (XT/ST/LT) / XAVC I / XAVC L |
| 图片 | PNG / JPG / WEBP / BMP / TIFF / PSD / SVG | — |
| 音频 | MP3 / WAV / FLAC / AAC / OGG / M4A | — |
| 字幕 | SRT / ASS / SSA / VTT | — |
| 项目 | XML (FCP/Premiere) / AAF / EDL | — |
| LUT | .cube / .3dl / .csp | — |
| 人偶 | Spine JSON / Live2D .moc3 | — |

### 3.2 渲染导出

| 类型 | 格式 | 说明 |
|------|------|------|
| 视频 | MP4 / MKV / MOV / WebM | 见发布页参数 |
| 音频 | WAV / MP3 / FLAC / AAC | 单独导出音频 |
| 帧序列 | PNG / EXR / TIFF | 逐帧导出 |
| GIF | GIF | 动图导出 |
| 项目包 | .2dw | 完整项目打包 |
| XML | FCP XML / Premiere XML | 交换格式 |
| LUT | .cube | 导出调色为 LUT |

### 3.3 导出参数

**帧序列导出：**

| 参数 | 选项 | 默认 |
|------|------|------|
| 格式 | PNG / EXR / TIFF | PNG |
| 质量 | 1-100 (PNG) / 16bit/32bit (EXR) | 100 / 16bit |
| 命名 | {name}_{seq} / {name}_{frame} | {name}_{seq} |
| 起始帧 | number | 0 |
| 结束帧 | number | 最后一帧 |

**GIF 导出：**

| 参数 | 范围 | 默认 |
|------|------|------|
| 宽度 | 128-1024 | 480 |
| 帧率 | 5-30 | 15 |
| 颜色数 | 32-256 | 128 |
| 循环 | 无限 / 指定次数 | 无限 |
| 抖动 | on/off | on |
