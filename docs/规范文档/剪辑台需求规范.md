# 二维工坊 · 剪辑台 面板需求规范

## 一、总体布局（五区 Grid）

```
┌─────────────────────────────────────────────────────────┐
│                   顶部工具栏 (40px)                       │
├──────────┬─────────────────────────┬────────────────────┤
│          │                         │                    │
│  可隐藏   │      实时监看区           │    控件面板         │
│  素材库   │      (16:9)             │    (280px)         │
│ (240px)  │                         │                    │
│          ├─────────────────────────┤                    │
│          │      多轨时间线           │                    │
│          │      (默认200px,可拖拽)   │                    │
└──────────┴─────────────────────────┴────────────────────┘
```

**Grid 定义：**
```css
grid-template-columns: 240px 1fr 280px;
grid-template-rows: 40px 1fr 200px;
grid-template-areas:
  "toolbar toolbar toolbar"
  "media   monitor  props"
  "media   timeline timeline";
```

## 五、中下 — 多轨时间线

### 5.1 轨道头（左侧固定 160px）

每条轨道头结构：
```
[色条4px] [轨道名] [🔒] [👁]
```

| 轨道 | 颜色 | 类型 |
|------|------|------|
| V1 | `var(--ho-track-v1)` #6a8aaa | 视频 |
| V2 | `var(--ho-track-v2)` #7a9a6a | 视频 |
| V3 | `var(--ho-track-v3)` #8a7aaa | 视频 |
| A1 | `var(--ho-track-a1)` #aa8a6a | 音频 |
| A2 | `var(--ho-track-a2)` #8a6a8a | 音频 |

每条轨道高度：36px

### 5.2 时间线内容区（水平滚动）

**时间刻度尺（顶部 24px）：**
- 标记：0s / 5s / 10s / 15s / 20s / 25s / 30s / 35s
- 字体：9px tertiary 色
- 竖线标记

**素材片段样式：**
```css
.tl-clip {
  position: absolute;
  top: 4px; height: 28px;
  border-radius: var(--ho-radius-xs);
  background: rgba(轨道色, 0.12~0.15);
  border-left: 2px solid var(--ho-track-xx);
  font-size: 10px;
  color: rgba(255,255,255,0.8);
}
```

**默认片段排列：**

| 轨道 | 片段 | 位置 |
|------|------|------|
| V1 | 开场镜头 | 2%-20% |
| V1 | 产品展示 | 22%-52% |
| V1 | 结尾 | 75%-95% |
| V2 | 叠加素材 | 15%-35% |
| V2 | Logo | 70%-80% |
| V3 | 字幕条 | 5%-90% |
| A1 | 主音频 | 0%-95% |
| A2 | 背景音乐 | 5%-95% |

**选中态：**
- `border-color: var(--ho-accent)`
- `box-shadow: 0 0 0 1px rgba(122,158,196,0.2)`

**拖拽手柄：** 选中时显示，左右各 6px 宽

**播放头：**
- 红色竖线 `var(--ho-accent)`
- 顶部三角手柄
- z-index: 10

**旗标标记：**
```css
.tl-marker::before { /* 三角形 */ border-top: 6px solid var(--ho-marker); }
.tl-marker::after  { /* 竖线 */ background: var(--ho-marker); opacity: 0.4; }
.marker-label { font-size: 9px; color: var(--ho-marker); }
```

默认旗标：入点(12%) / 转场(55%) / 出点(88%)
