# 二维工坊 · 推荐扩展功能规范

> 基于当前功能集的行业对标分析，推荐以下扩展功能以提升专业竞争力。

---

## 一、AI 智能功能

### 1.1 AI 超分辨率 (Super Resolution)

| 参数 | 选项 | 说明 |
|------|------|------|
| 模型 | Real-ESRGAN / waifu2x / Topaz-like | 本地ONNX推理 |
| 放大倍率 | 2x / 4x | 支持任意倍率 |
| 去噪强度 | 0~100% | 抑制放大噪点 |
| 锐化 | 0~100% | 输出锐度增强 |
| 批量处理 | 支持 | 多帧/多文件队列 |

**使用场景：** 低分辨率素材放大、老旧影像修复、4K输出准备

### 1.2 AI 帧插值 (Frame Interpolation)

| 参数 | 选项 | 说明 |
|------|------|------|
| 模型 | RIFE / FILM / AMT | 本地推理 |
| 目标帧率 | 2x / 4x / 自定义 | 原始帧率→目标帧率 |
| 运动补偿 | 自动 | 处理遮挡/模糊 |
| 质量模式 | 标准 / 高质量 | 速度vs质量权衡 |

**使用场景：** 24fps→60fps平滑、慢动作生成、运动模糊消除

### 1.3 AI 场景检测 (Scene Detection)

| 参数 | 选项 | 说明 |
|------|------|------|
| 灵敏度 | 低 / 中 / 高 | 切割阈值 |
| 最小时长 | 0.5s ~ 5s | 防止过度切割 |
| 输出方式 | 时间线分割 / 标记列表 | 自动标记切割点 |
| 内容感知 | 视觉+音频 | 综合判断场景变化 |

**使用场景：** 粗剪自动分段、长视频素材整理

### 1.4 AI 自动构图 (Auto Reframe)

| 参数 | 选项 | 说明 |
|------|------|------|
| 目标比例 | 16:9 / 9:16 / 1:1 / 4:3 | 智能裁切 |
| 跟踪主体 | 人脸 / 人物 / 自定义 | 智能跟随 |
| 平滑度 | 低 / 中 / 高 | 运动平滑 |
| 保护区域 | 手动 | 关键内容不被裁切 |

**使用场景：** 横屏→竖屏转换、多平台发布适配

### 1.5 AI 音频功能

| 功能 | 说明 | 推荐模型 |
|------|------|----------|
| 人声分离 | 分离人声/伴奏/音效 | Demucs / Spleeter |
| 降噪 | 智能去除背景噪声 | RNNoise / DCCRN |
| 语音转文字 | 自动字幕生成 | Whisper / Paraformer |
| 文字转语音 | AI配音生成 | VITS / Bark |
| 语音翻译 | 实时字幕翻译 | NLLB / M2M-100 |

### 1.6 AI 运动跟踪 (Motion Tracking)

| 功能 | 说明 |
|------|------|
| 点跟踪 | 跟踪指定像素点运动 |
| 区域跟踪 | 跟踪矩形/自由区域 |
| 人脸追踪 | 检测并追踪人脸 |
| 物体追踪 | 检测并追踪任意物体 |
| 数据导出 | 输出跟踪数据到关键帧 |

**使用场景：** 稳定器、动态文字、特效跟随、遮罩动画

## 二、专业工作流功能

### 2.1 代理工作流 (Proxy Workflow)

| 参数 | 选项 | 说明 |
|------|------|------|
| 代理生成 | 自动 / 手动 | 导入时自动创建 |
| 代理分辨率 | 1/2 / 1/4 / 1/8 | 可配置 |
| 代理编码 | H.264 / ProRes Proxy | 快速解码 |
| 切换 | 实时 | 代理↔原始一键切换 |
| 存储位置 | 项目缓存目录 | 可配置 |

**使用场景：** 4K/8K素材流畅编辑、低配电脑性能优化

### 2.2 多机位编辑 (Multi-Cam)

| 参数 | 说明 |
|------|------|
| 机位数量 | 最多9机位 |
| 同步方式 | 时间码 / 音频波形 / 手动标记 |
| 切换预览 | 实时多画面监看 |
| 实时切换 | 点击即切，自动记录 |
| 音频源 | 指定/自动切换 |
| 角度合并 | 合并为多机位片段 |

### 2.3 嵌套序列 (Nested Sequence)

| 参数 | 说明 |
|------|------|
| 嵌套 | 将多个片段组合为独立单元 |
| 编辑 | 双击进入编辑 |
| 效果 | 对嵌套整体应用效果 |
| 嵌套层数 | 最多5层 |
| 渲染 | 嵌套预渲染优化性能 |

### 2.4 模板系统 (Template)

| 类型 | 说明 |
|------|------|
| 项目模板 | 预设分辨率/帧率/色彩空间 |
| 字幕模板 | 预设样式/动画 |
| 转场模板 | 预设转场效果 |
| 调色预设 | 预设调色参数 |
| 导出预设 | 预设编码/封装参数 |

## 三、HDR 工作流

### 3.1 HDR 输出支持

| 标准 | 说明 | 支持 |
|------|------|------|
| HDR10 | 静态元数据，最广泛 | ✓ |
| HDR10+ | 动态元数据，三星/松下 | ✓ |
| Dolby Vision | 动态元数据，最高品质 | ✓ |
| HLG | 直播兼容 | ✓ |

### 3.2 HDR 色彩管理

| 参数 | 选项 | 说明 |
|------|------|------|
| 色调映射 | Hable / Reinhard / ACES | HDR→SDR预览 |
| 亮度映射 | 1000 / 4000 / 10000 nits | 目标峰值亮度 |
| 色域 | Rec.2020 / DCI-P3 | 输出色域 |
| 元数据 | 手动 / 自动生成 | 写入HDR元数据 |

### 3.3 HDR 监看

- 支持 HDR 显示器直接输出
- 色调映射预览 (SDR监视器)
- 亮度/色域合规性检查
