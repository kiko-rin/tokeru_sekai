### 1.2 顶部工具栏 (40px)

| 位置 | 元素 | 说明 |

### 1.3 监看区

- 16:9 黑色背景
- CSS 渐变示意画面
- 分屏模式：左右分割线（可拖拽），左原图右调色后
- 底部叠加：示波器小图（60px 高，波形示意）

### 1.4 素材缩略图时间线

- 横向滚动，6 个缩略图方块
- 64×36px，圆角 4px
- 选中态：2px accent 边框

### 1.5 调色工具面板（右侧 320px）

**Tab 切换：** 基础校色 / 曲线 / 色轮 HSL / LUT

#### 基础校色 Tab

**色轮（140px 直径）：**
- `conic-gradient` 灰阶色相环
- 中心可拖拽点：accent 实心 + border
- 2px border `var(--ho-border)`

**滑块列表：**

| 参数 | 范围 | 默认 |
|------|------|------|
| 亮度 | -100~100 | 0 |
| 对比度 | -100~100 | 10 |
| 饱和度 | -100~100 | 15 |
| 色温 | -100~100 | 5 |
| 色调 | -100~100 | 0 |
| 曝光 | -100~100 | 8 |
| 高光 | -100~100 | -15 |
| 阴影 | -100~100 | 20 |

每行：`[label 56px] [range flex-1] [value 36px]`

#### 曲线 Tab

- 通道按钮组：RGB / R / G / B（选中态 accent-bg + accent 文字）
- 曲线编辑器：160px 高
  - 网格背景（pattern 20×20px）
  - 对角虚线参考线
  - 曲线路径（accent 1.5px）
  - 控制点：白色圆 + accent 边框
  - 端点：accent 实心 4px

#### 色轮 HSL Tab

- 三个色轮横排（80px 直径/个）：高光 / 中间调 / 阴影
  - 每个：`conic-gradient` 灰阶 + 可拖拽点
  - 底部标签：10px tertiary 色
- 下方滑块：H 偏移 / S 偏移 / L 偏移

#### LUT Tab

- 预设网格（3列）：6 个灰色方块
- 选中态：2px accent 边框
- 底部：`+ 导入自定义 LUT` 按钮

```
┌──────────────────────────────────────────────────┐
│              顶部工具栏 (40px)                      │
├──────────────────────────┬────────────────────────┤
│                          │                        │
│   音频轨时间线             │   频谱/效果器面板       │
│   (flex-1)               │   (360px)              │
│                          │                        │
├──────────────────────────┤                        │
│   响度/监看控制台          │                        │
│   (120px)                │                        │
└──────────────────────────┴────────────────────────┘
```

### 2.2 顶部工具栏 (40px)

| 位置 | 元素 | 说明 |
|------|------|------|
| 左 | 返回按钮 | → 剪辑台 |
| 左 | 录音按钮 | `○` 图标，tertiary 色 |
| 左 | 节拍器按钮 | `·` 图标 |
| 中 | 播放按钮 | `▶` 图标 |
| 中 | 时间码 | mono 字体，accent 色 |
| 右 | 监听模式下拉 | 立体声 / 单声道 |
| 右 | 导出音频按钮 | |

### 2.3 音频轨时间线（左侧 flex-1）

#### 轨道头（160px）

| 轨道 | 颜色 | 按钮 |
|------|------|------|
| A1 主音频 | `var(--ho-track-a1)` | M / S |
| A2 背景音乐 | `var(--ho-track-a2)` | M / S |
| A3 音效 | `#8a7aaa` | M / S |
| A4 配音 | `#6b9e7a` | M / S |

每条轨道 40px 高，带微型音量推子

#### 时间线内容区

- 时间刻度尺（20px）：0s / 10s / 20s / 30s
- 音频波形片段（CSS 条纹模拟）：
  - A1：密集型人声波形，暖灰轨道色
  - A2：舒缓型音乐波形，冷灰轨道色
  - A3：短促型音效片段（15%/40%/60%位置）
  - A4：空轨道
- 播放头：accent 色竖线

### 2.4 频谱/效果器面板（右侧 360px）

**Tab 切换：** 频谱 / 效果器 / 特效列表

#### 频谱 Tab

- 频谱显示区（120px 高）
  - 20 个竖条，CSS animation 模拟跳动
  - `background: linear-gradient(to top, rgba(122,158,196,0.15), rgba(122,158,196,0.5))`
  - `@keyframes spectrum-bounce` 随机高度动画
- 频率刻度：20Hz / 100 / 500 / 1k / 5k / 10k / 20kHz
- 底部：FFT 大小选择 / 窗函数选择

#### 效果器 Tab

效果器链（垂直堆叠）：

| 效果器 | 参数 |
|--------|------|
| EQ 均衡器 | 60Hz / 1kHz / 8kHz 三个滑块 |
| 压缩器 | 阈值 / 比率 两个滑块 |
| 混响 | 房间 / 衰减 两个滑块 |

每项结构：
```
[图标] [效果器名] [B旁路] [✕删除]
[参数滑块行]
```

旁路按钮 on 态：accent-bg + accent 边框
底部：`+ 添加效果器` 按钮

#### 特效列表 Tab

2 列卡片网格（10 个）：

| 卡片 | 图标 | 名称 | 描述 |
|------|------|------|------|
| 降噪 | `·` | 降噪 | 去除背景噪声 |
| 去齿音 | `·` | 去齿音 | 消除齿音嘶声 |
| 去嗡嗡声 | `·` | 去嗡嗡声 | 消除低频嗡声 |
| 均衡器 | `·` | 均衡器 | 频率均衡调节 |
| 压缩器 | `·` | 压缩器 | 动态范围压缩 |
| 混响 | `·` | 混响 | 空间混响效果 |
| 延迟 | `·` | 延迟 | 时间延迟效果 |
| 合唱 | `·` | 合唱 | 合唱镶边效果 |
| 失真 | `·` | 失真 | 过载失真效果 |
| 限制器 | `·` | 限制器 | 峰值限制保护 |

### 2.5 响度/监看控制台（底部 120px）

三栏布局：

**左栏 — 响度表：**
- LUFS 大号数字（28px mono，accent 色）
- LRA 显示
- 峰值条（渐变 safe→warning→peak）
- 响度标准：EBU R128 / ATSC A/85 / YouTube

**中栏 — 各轨道 VU 表：**
- 4 个竖条（12px 宽，60px 高）
- 渐变：`linear-gradient(to top, var(--ho-safe), var(--ho-warning), var(--ho-peak))`
- 峰值保持指示

**右栏 — 主输出：**
- 主音量推子（竖直 range）
- 监听音量推子
- 输出值：`0 dB` mono 字体

## 三、发布页面

### 3.1 布局

居中卡片式，`max-width: 800px; margin: 0 auto; padding: 24px;`

### 3.2 预览区

- 16:9 黑色圆角容器
- 中央播放按钮（48px 圆形半透明）
- 底部信息：`时长: 00:45 · 预计大小: ~125 MB`

### 3.3 编码设置卡片

| 参数 | 控件 | 选项 |
|------|------|------|
| 编码格式 | select | H.264 / H.265 (HEVC) / VP9 / AV1 |
| 封装格式 | select | MP4 / MKV / MOV / WebM |
| 分辨率 | select | 1920×1080 / 3840×2160 / 1280×720 / 自定义 |
| 帧率 | select | 24 / 25 / 30 / 60 |
| 码率模式 | toggle 按钮组 | CBR / VCRF |
| 视频码率 | range 1-100 Mbps + 数值 | 默认 20 Mbps |
| 编码器 | select | 软件编码 / NVIDIA NVENC / AMD AMF / Intel QSV |
| 色彩空间 | select | Rec.709 / Rec.2020 / sRGB |

### 3.4 音频设置卡片

| 参数 | 控件 | 选项 |
|------|------|------|
| 编码 | select | AAC / FLAC / OPUS / PCM |
| 码率 | select | 128 / 192 / 256 / 320 kbps |
| 采样率 | select | 44100 / 48000 / 96000 Hz |
| 声道 | select | 立体声 / 5.1 / 7.1 |

### 3.5 输出设置卡片

| 参数 | 控件 |
|------|------|
| 输出路径 | input + 浏览按钮 |
| 文件名模板 | input，支持 `{project}_{date}` 变量 |

### 3.6 底部按钮栏

- 保存预设（默认按钮）
- 添加到队列（默认按钮）
- 开始渲染（primary 大按钮，40px 高）
