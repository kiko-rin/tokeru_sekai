### 0.2 LUT 状态自动检测

检测素材是否已烧入 LUT（Baked-in LUT）：

| 检测方法 | 说明 |
|----------|------|
| XMP/元数据读取 | 读取 `lutApplied` / `colorLook` 等XMP标签 |
| 传输函数分析 | 分析像素值分布是否符合已知Log曲线 |

### 0.4 自动色彩还原

**功能描述：** 根据素材厂商和Log曲线，自动应用正确的还原LUT，将Log素材转换到线性空间。

| 参数 | 控件 | 默认 | 说明 |
|------|------|------|------|
| 自动色彩还原 | toggle | on | 新素材导入时自动应用 |
| 还原LUT库 | 下拉选择 | 系统内置 | 用户可指定LUT库中的LUT |
| 强制覆盖 | toggle | off | 已有LUT的素材也重新还原 |

**还原LUT映射表（内置）：**

| Canon C-Log | `clog_to_linear.cube` | C-Log → Linear |
| Canon C-Log2 | `clog2_to_linear.cube` | C-Log2 → Linear |
| Canon C-Log3 | `clog3_to_linear.cube` | C-Log3 → Linear |
| Panasonic V-Log | `vlog_to_linear.cube` | V-Log → Linear |
| RED Log3G10 | `red_log3g10_to_linear.cube` | Log3G10 → Linear |
| ARRI LogC3 | `arrilogc3_to_linear.cube` | LogC3 → Linear |
| ARRI LogC4 | `arrilogc4_to_linear.cube` | LogC4 → Linear |

### 0.5 自动色彩统一

**功能描述：** 将不同厂商、不同拍摄条件的素材统一到一致的色彩外观，确保混合剪辑时色彩连贯。

| 参数 | 控件 | 范围 | 默认 | 说明 |
|------|------|------|------|------|
| 自动色彩统一 | toggle | on/off | on | 启用统一处理 |
| 统一强度 | range | 0~100% | 70% | 统一效果的强弱 |
| 目标色温 | range | 2000~12000K | 5600K | 统一的目标色温 |
| 目标色调 | range | -100~+100 | 0 | 统一的目标色调偏移 |
| 目标饱和度 | range | 0~200% | 100% | 统一的目标饱和度 |
| 目标对比度 | range | 0.5~2.0 | 1.0 | 统一的目标对比度 |

**统一算法：**

```
1. 分析每个素材帧的色彩统计:
   - 平均色温/色调
   - 平均饱和度
   - 亮度分布 (暗部/中间调/高光)
   
2. 与目标标准比较，计算偏差:
   - 色温偏差 ΔT
   - 色调偏差 Δtint
   - 饱和度偏差 Δsat
   - 对比度偏差 Δcontrast
   
3. 应用修正 (使用统一强度控制):
   - 修正值 = 偏差 × 统一强度
   
4. 输出统一后的帧
```

## 一、Raw素材处理流程

### Sony X-OCN 素材

当导入 X-OCN 素材时，调色管线自动执行以下流程：

```
X-OCN 原始帧 (12/16-bit Linear 或 S-Log3)
    ↓
厂商识别 → 标注 "Sony · X-OCN ST · S-Log3 · S-Gamut3.Cine"
    ↓
自动色彩还原 (若开启)
    ↓ 应用 slog3_to_linear.cube
色彩空间转换 (S-Gamut3.Cine → 工作空间 Rec.2020 Linear)
    ↓
内部处理空间 (Linear Float32, 16-bit精度)
    ↓
自动色彩统一 (若开启)
    ↓ 色温/色调/饱和度/对比度 统一到目标值
用户调色参数应用
    ↓
输出色彩空间转换 (工作空间 → Rec.709 / Rec.2020 / DCI-P3)
    ↓
最终输出
```

### 多厂商素材混合工作流

当项目中混合使用不同厂商素材时：

```
┌─────────────────────────────────────────────────────────┐
│ 素材A (Sony S-Log3)    素材B (Canon C-Log3)    素材C (ARRI LogC4) │
│     ↓                        ↓                        ↓         │
│ 自动还原LUT              自动还原LUT              自动还原LUT      │
│ slog3_to_linear.cube     clog3_to_linear.cube    arrilogc4_to_linear.cube │
│     ↓                        ↓                        ↓         │
│ 统一到 Rec.2020 Linear   统一到 Rec.2020 Linear   统一到 Rec.2020 Linear │
│     ↓                        ↓                        ↓         │
│              ↓ 自动色彩统一 (统一强度/目标色温/饱和度) ↓                │
│              ↓                                             ↓                │
│     ┌────────────────────────────────────────────┐            │
│     │         统一后的素材 (外观一致)              │            │
│     └────────────────────────────────────────────┘            │
│                          ↓                                    │
│                  用户调色 → 输出                                │
└─────────────────────────────────────────────────────────┘
```

**自动检测：**
- 检测素材的 Log 曲线 (S-Log2/S-Log3/C-Log3/V-Log等) → 自动应用正确的反Gamma
- 检测色域 (S-Gamut3.Cine/Cinema Gamut/V-Gamut等) → 自动应用正确的色彩矩阵
- 检测色深 (12-bit/16-bit/10-bit) → 自动选择合适的处理精度
- 检测是否已应用LUT → 显示状态标注

## 四、LUT 管理

### 4.1 LUT 格式支持

| 格式 | 后缀 | 说明 | 解析方式 |
|------|------|------|----------|
| Cube | `.cube` | DaVinci Resolve / Adobe 标准 | 逐行解析 TITLE/LUT_3D_SIZE/DOMAIN |
| 3DL | `.3dl` | Autodesk 标准 | 解析大小头 + RGB值归一化 |
| CSP | `.csp` | Color Space Plugin (FilmLight) | 解析 Description + FromInput + 数据段 |

**插值方式：** 四面体插值 (Tetrahedral interpolation) — 业界最高精度 LUT 插值算法，避免三线性插值的色彩偏移。

### 4.2 LUT 参数

| 参数 | 类型 | 说明 |
|------|------|------|
| LUT 大小 | 自动检测 | 17×17×17 / 33×33×33 / 65×65×65 |
| 强度 | range 0-100% | LUT 效果混合比例（默认 100） |
| 色彩空间 | select | Rec.709 / Rec.2020 / Log |

### 4.3 内部处理

- LUT 在 Linear Float32 空间中应用 (16-bit 精度)
- 应用顺序：输入色彩空间转换 → LUT 应用 → 输出色彩空间转换
- WebGL2 GPU 加速着色器实现 LUT 查找

### 4.3 预设 LUT（内置 6 个）

| 名称 | 效果描述 |
|------|----------|
| 电影冷调 | 降饱和 + 冷色温 + 压高光 |
| 复古暖调 | 加暖色温 + 降对比度 + 褪色黑 |
| 高对比 | 大幅提升对比度 + 压阴影 |
| 黑白经典 | 去饱和 + 调整红绿蓝权重 |
| 日系清新 | 提亮度 + 降饱和 + 偏青绿 |
| 赛博朋克 | 高饱和 + 青色高光 + 橙色阴影 |

### 4.4 导入/导出

- 导入：`dialog.showOpenDialog({ filters: [{ name: 'LUT', extensions: ['cube','3dl','csp'] }] })`
- 导出：将当前调色参数导出为 .cube 文件
- 存储路径：`~/.2d-workshop/luts/`

## 六、示波器

> 所有示波器均使用 WebGL2 GPU 加速计算，实时刷新率 ≥ 30fps。

### 6.1 波形图 (Waveform)

- 尺寸：100% × 60px
- 横轴：画面水平像素
- 纵轴：亮度 0-100%
- 颜色：rgba(122,158,196,0.3) 填充
- 参考线：0% / 50% / 100% 水平虚线
- **计算方式：** WebGL2 着色器在 GPU 上完成 YUV→亮度 映射，输出到纹理后绘制

### 6.2 RGB 分量波形 (RGB Parade)

- 尺寸：100% × 60px
- 三通道并排显示 (R / G / B)
- 各通道使用对应颜色
- **计算方式：** 单次 WebGL2 pass 提取三通道，输出到同一纹理的不同区域

### 6.3 矢量示波器 (Vectorscope)

- 尺寸：120×120px 圆形
- 显示色相-饱和度分布 (UV 色度平面)
- 参考网格：色相环 + 饱和度圈
- 目标标记：R/G/B/C/M/Y 六点
- 支持 Rec.709 / Rec.2020 gamut overlay
- **计算方式：** WebGL2 着色器将 RGB→UV 映射，256×256 分辨率累加

### 6.4 直方图 (Histogram)

- 尺寸：100% × 40px
- R/G/B 三通道叠加 + 亮度通道
- 各通道半透明对应色
- 横轴：亮度 0-255
- 纵轴：像素计数 (支持对数/线性刻度)
- 256 bins
- **计算方式：** WebGL2 着色器原子操作累加像素到 bin

### 6.5 示波器数据接口

```typescript
interface ScopeRenderer {
  compute(imageData: ImageData): void
  drawToCanvas(ctx: CanvasRenderingContext2D): void
  resize(width: number, height: number): void
}
```
