# 创绘面板 — 完整项目需求文档 (PRD)

> 本文档为创绘面板的正式开发规范，用于指导 AI 编码工作。
> 开发模型：DeepSeek V4 Flash
> 最后更新：2026-07-23

---

## 一、模块概述

创绘面板是二维工坊的第4个工作区Tab，包含两种并列的工作模式：

| 模式 | 定位 | 核心技术 |
|------|------|---------|
| **手绘模式** | 位图绘制 + 动态MR合成 | Canvas 2D + OffscreenCanvas + WebGL2 |
| **人偶模式** | Spine 2D骨骼动画预览与录制 | spine-webgl.js (用户自行提供) |

两种模式共享同一个监看画布区域，可通过 Tab 切换，各自独立维护状态。

---

## 二、手绘模式

### 2.1 画布引擎

- 画布使用 `OffscreenCanvas` 在 Worker 中进行像素运算，主线程仅负责合成与显示
- 支持缩放 (pinch/scroll) + 平移 (space+drag)
- 默认画布尺寸跟随项目设置 (如 1920x1080)，可手动修改
- 背景支持纯色 / 透明棋盘格 / 导入底图
- 实时显示坐标标尺 (Rulers) 和参考线 (Guides)

### 2.2 触控笔输入

**数据来源：** 捕获 Wacom/Huion 等数位板驱动通过 Pointer Events API 暴露的数据，**不依赖 Windows Ink API**。

捕获属性：
| 属性 | PointerEvent字段 | 说明 |
|------|-----------------|------|
| 压力 | `pressure` | 0.0 ~ 1.0，映射到笔刷大小/不透明度 |
| 倾斜X | `tiltX` | -90 ~ 90 度 |
| 倾斜Y | `tiltY` | -90 ~ 90 度 |
| 方位角 | `azimuthAngle` | 0 ~ 2π (rad) |
| 仰角 | `altitudeAngle` | 0 ~ π/2 (rad) |
| 笔ID | `pointerId` | 多笔触区分 |
| 按键 | `button` | 左键/右键/中键/橡皮擦(eraser) |

**事件处理要求：**
- 使用 `pointerdown` / `pointermove` / `pointerup` 事件
- `pointermove` 必须设置 `{ capture: true }` 确保跨窗口不丢帧
- 设置 `touch-action: none` CSS 阻止浏览器默认手势
- 压感曲线可配置 (线性 / 二次 / 自定义 LUT)
- 每个采样点插值密度不低于 60Hz

### 2.3 笔刷引擎

#### 2.3.1 基础笔刷类型

| 类型 | 实现方式 | 说明 |
|------|---------|------|
| 圆形硬笔 | 逐点stamp + 压感缩放 | 基础绘画 |
| 圆形软笔 | 高斯衰减stamp | 喷枪效果 |
| 线性涂抹 | 上下文 getImageData 混合 | 涂抹工具 |
| 橡皮擦 | `destination-out` 合成模式 | 擦除 |
| 填充 | Flood fill 算法 | 油漆桶 |
| 吸管 | 采样指定像素颜色 | 取色器 |

#### 2.3.2 笔刷参数

每个笔刷实例包含以下可调参数：

```typescript
interface BrushParams {
  size: number          // 像素直径，1 ~ 500
  opacity: number       // 不透明度 0 ~ 1
  flow: number          // 流量 0 ~ 1 (累积速度)
  hardness: number      // 硬度 0 ~ 1 (边缘衰减)
  spacing: number       // 间距 1% ~ 100% (stamp间隔占笔刷直径百分比)
  scatterX: number      // X轴散布 0 ~ 100%
  scatterY: number      // Y轴散布 0 ~ 100%
  angle: number         // 笔刷角度 0 ~ 360°
  roundness: number     // 圆度 0 ~ 1 (1=正圆, 0=线)
  pressureSize: boolean // 压感控制大小
  pressureOpacity: boolean // 压感控制不透明度
  tiltSize: boolean     // 倾斜控制大小
  tiltOpacity: boolean  // 倾斜控制不透明度
}
```

#### 2.3.3 笔刷库格式

支持导入两种格式的笔刷预设文件：

**PS笔刷 (.abr)**
- 解析 ABR v1/v2/v3/v6 格式头部
- 提取笔刷形状 (灰度位图)、直径、硬度、间距
- 懒加载：文件索引先读取，实际纹理数据仅在选中笔刷时解压加载

**SAI2笔刷**
- 解析 `spray` / `brush` / `pen` 参数文件
- 映射 SAI2 特有的笔刷参数到本引擎参数
- SAI2 笔刷纹理 (.bmp/.png) 需同目录放置

**导入流程：**
```
用户选择文件 → 解析文件头 → 创建索引 → 仅在UI列表中显示名称和缩略图
用户点击笔刷 → 懒加载实际纹理数据 → 缓存到内存 (LRU, 最多50个)
```

#### 2.3.4 笔刷纹理

笔刷纹理使用 `CanvasPattern` 或自定义纹理贴图：
- 支持 .png / .bmp 灰度纹理
- 纹理混合模式：叠加 / 正片叠底 / 柔光
- 纹理可旋转 (跟随笔刷角度)

### 2.4 图层系统

#### 2.4.1 图层数据结构

```typescript
interface Layer {
  id: string
  name: string
  type: 'raster' | 'group' | 'adjustment'
  visible: boolean
  opacity: number          // 0 ~ 1
  blendMode: BlendMode
  locked: boolean
  canvas: OffscreenCanvas  // 实际像素数据
  mask?: CanvasMask        // 图层蒙版
  effects: LayerEffect[]   // 图层效果
  children?: Layer[]       // 仅 group 类型
}

enum BlendMode {
  Normal, Multiply, Screen, Overlay, SoftLight, HardLight,
  ColorDodge, ColorBurn, Darken, Lighten, Difference, Exclusion,
  Hue, Saturation, Color, Luminosity, Add, Subtract
}
```

#### 2.4.2 图层操作

- 新建图层 / 新建组
- 删除图层 / 复制图层
- 上移 / 下移 / 合并向下 / 合并可见
- 锁定 (透明度/位置/全部)
- 蒙版 (显示/隐藏选区)
- 剪贴蒙版 (Clipping Mask)

#### 2.4.3 图层蒙版

- 与父图层共享尺寸
- 使用灰度通道控制可见性
- 支持画笔直接在蒙版上绘制

### 2.5 MR (Mixed Reality) 动态合成

#### 2.5.1 功能描述

手绘模式中，每个图层可设置为"MR动态图层"，该图层的内容将作为前景元素与时间线上的视频帧进行实时合成预览。

#### 2.5.2 合成流程

```
视频帧 (时间线当前帧)
    ↓
背景图层 (normal blend)
    ↓
MR图层: 读取当前图层 OffscreenCanvas 数据
    ↓
根据图层 blendMode 进行 GPU 合成
    ↓
叠加图层效果 (投影/发光/描边等)
    ↓
输出到监看画布
```

#### 2.5.3 MR图层特性

- 图层可关联时间线关键帧，在不同时间点显示不同内容
- 支持图层变换动画 (位移/旋转/缩放/倾斜)
- 图层可设置为"跟随时间线"或"固定帧"
- 合成使用 WebGL2 着色器实现，保证实时性

#### 2.5.4 关键帧与时间轴

- 画布下方显示简化版时间轴 (仅当前选中图层的关键帧)
- 关键帧属性：时间码 / 图层可见性 / 变换参数 / 不透明度
- 关键帧可拖拽移动、复制、删除
- 支持缓动曲线 (线性 / 贝塞尔 / 弹跳 / 弹性)

```typescript
interface Keyframe {
  id: string
  time: number           // 帧号
  layerId: string
  properties: {
    visible?: boolean
    opacity?: number
    transform?: {
      x: number; y: number
      rotation: number
      scaleX: number; scaleY: number
      pivotX: number; pivotY: number
    }
  }
  easing: EasingType
}

enum EasingType {
  Linear, EaseIn, EaseOut, EaseInOut,
  CubicIn, CubicOut, CubicInOut,
  BounceIn, BounceOut, ElasticIn, ElasticOut
}
```

## 三、人偶模式

### 3.1 技术约束

> **关键约束：** spine-webgl.js 运行时文件 **不由本项目提供**。
> 用户必须自行准备 `spine-webgl.js` 文件并手动放入指定目录。
> 项目仅提供 TypeScript 类型定义 (`spine-webgl.d.ts`) 和胶水代码。

原因：Spine Runtime 使用 MIT + 商业双许可协议，自行分发存在侵权风险。

### 3.2 用户操作流程

```
1. 用户从 Esoteric Software 官网下载 Spine Runtime (spine-webgl.js)
2. 将 spine-webgl.js 放入项目目录: src/renderer/public/spine/
3. 启动应用，人偶模式检测 spine-webgl.js 是否存在
4. 若不存在 → 显示引导页面，提供下载链接和操作说明
5. 若存在 → 动态加载 spine-webgl.js，进入人偶模式
```

### 3.3 Spine 集成

#### 3.3.1 运行时加载

```typescript
// 不使用 import，而是动态加载用户提供的文件
async function loadSpineRuntime(): Promise<void> {
  const script = document.createElement('script')
  script.src = '/spine/spine-webgl.js'
  document.head.appendChild(script)
  await new Promise<void>((resolve, reject) => {
    script.onload = () => resolve()
    script.onerror = () => reject(new Error('spine-webgl.js not found'))
  })
}
```

#### 3.3.2 类型声明

项目中需要提供 `spine-webgl.d.ts` 类型声明文件，覆盖 spine-webgl.js 暴露的全局 `spine` 命名空间，使 TypeScript 能正确识别类型。类型声明参考已有的 `docs/spine/spine.ts` 中的用法。

#### 3.3.3 参考实现

`docs/spine/` 目录中包含完整参考实现：

| 文件 | 说明 |
|------|------|
| `spine-webgl.js` | Spine WebGL 运行时 (用户需自行更新版本) |
| `spine.ts` | Spine 封装类，处理加载/渲染/动画/录制 |
| `spine.vue` | Vue 版 UI 面板 (参考布局和交互逻辑) |

**必须参考这些文件理解 Spine 集成模式，但将其从 Vue 改写为 React。**

## 四、共享基础设施

### 4.1 画布合成管线

两种模式共享最终的监看合成管线：

```
Video Frame (时间线当前帧, 来自渲染进程的视频解码)
    ↓
Background Layer (底色/底图)
    ↓
Drawing Layers (手绘模式图层栈)
    ↓
Spine Overlay (人偶模式叠加，可选)
    ↓
UI Overlay (参考线/选区/变换框，仅编辑时显示)
    ↓
Final Output → 监看画布 (display canvas)
```

### 4.2 性能要求

| 指标 | 目标 |
|------|------|
| 绘画延迟 | < 16ms (60fps) |
| MR合成延迟 | < 33ms (30fps实时预览) |
| Spine渲染 | ≥ 30fps |
| 图层数量上限 | 100层 (受内存限制) |
| 笔刷纹理缓存 | LRU, 最大50个, 内存上限200MB |

## 六、技术决策记录

1. **画布使用 OffscreenCanvas**：将像素运算从主线程分离，保证 UI 响应
2. **Spine 动态加载而非 bundled**：规避 Spine Runtime 商业许可风险
3. **Pointer Events 而非 Windows Ink**：跨平台兼容，Wacom/Huion 驱动均支持
4. **笔刷文件懒加载**：.abr 文件可能很大 (数百MB)，仅加载需要的笔刷
5. **MR 合成使用 WebGL2**：与调色模块共享 WebGL2 上下文管线
6. **关键帧系统独立于时间线**：创绘面板的时间轴仅管理图层自身的关键帧，与全局时间线解耦
